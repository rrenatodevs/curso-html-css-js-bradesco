# Alternador de Tema Claro/Escuro

Site simples com um botão que alterna entre tema claro e escuro, feito no curso **"Crie um site simples usando HTML, CSS e JavaScript"** da Escola Virtual da Fundação Bradesco.

🔗 **Ver o site funcionando:** [link do GitHub Pages]

## Funcionalidades

- Botão que troca o tema da página entre claro e escuro
- O texto do botão muda conforme o tema ativo
- Cores controladas por variáveis CSS

## Tecnologias

- HTML5
- CSS3 (variáveis CSS e posicionamento)
- JavaScript (manipulação do DOM)

## Estrutura do projeto

```
├── index.html
├── css/
│   └── style.css
└── js/
    └── script.js
```

## O que aprendi

- Usar **variáveis CSS** (`:root` e `var()`) para trocar o tema inteiro mudando só uma classe
- Alternar classes com `classList.toggle()` e verificar o estado com `classList.contains()`
- Usar o atributo `defer` no `<script>` para o JavaScript rodar só depois de a página carregar
- Diferença entre `position: relative` e `position: absolute`

## Como rodar
